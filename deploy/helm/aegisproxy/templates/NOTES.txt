AegisProxy {{ .Chart.AppVersion }} deployed (storage: {{ .Values.storage.type }}, control-plane replicas: {{ include "aegis.cpReplicas" . }}).

1. Console / API
{{- if .Values.ingress.enabled }}
   https://{{ .Values.ingress.host }}
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aegis.cpService" . }} 8081:{{ .Values.controlPlane.service.port }}
   then open http://127.0.0.1:8081  (set publicUrl to the real external URL!)
{{- end }}

2. Bootstrap Super Admin "admin" password:
{{- if .Values.secrets.existingSecret }}
   key "bootstrap-admin-password" in Secret {{ .Values.secrets.existingSecret }} (or DATA_DIR/secrets/initial-admin-password)
{{- else }}
   kubectl -n {{ .Release.Namespace }} get secret {{ include "aegis.secretName" . }} -o jsonpath='{.data.bootstrap-admin-password}' | base64 -d; echo
{{- end }}
   Change it after the first login and create personal accounts.

3. Proxy endpoint for servers:
   kubectl -n {{ .Release.Namespace }} get svc {{ include "aegis.fullname" . }}-proxy
   (externalTrafficPolicy={{ .Values.dataPlane.service.externalTrafficPolicy }} preserves client IPs for server identification)

4. Distribute the enterprise root CA to servers:
   curl -fsSL {{ .Values.publicUrl }}/api/public/ca/install-linux.sh | sudo bash
   iwr -UseBasicParsing {{ .Values.publicUrl }}/api/public/ca/install-windows.ps1 | iex
{{- if and (not .Values.ca.existingSecret) .Values.ca.generate }}

NOTE: the CA was generated by Helm (RSA-2048). For production create it with
      `aegis-control-plane gen-ca` and reference it via ca.existingSecret.
{{- end }}
