1. Console / API
{{- if .Values.ingress.enabled }}
   https://{{ .Values.ingress.host }}
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aegis.cpService" . }} 8081:{{ .Values.controlPlane.service.port }}
   then open http://127.0.0.1:8081  (set publicUrl to the real external URL!)

2. Bootstrap Super Admin "admin" password:
{{- if .Values.secrets.existingSecret }}
   key "bootstrap-admin-password" in Secret {{ .Values.secrets.existingSecret }} (or DATA_DIR/secrets/initial-admin-password)
{{- else }}
   kubectl -n {{ .Release.Namespace }} get secret {{ include "aegis.secretName" . }} -o jsonpath='{.data.bootstrap-admin-password}' | base64 -d; echo
{{- end }}
   Change it after the first login and create personal accounts.

3. Proxy endpoint for servers:
   kubectl -n {{ .Release.Namespace }} get svc {{ include "aegis.fullname" . }}-proxy
   (externalTrafficPolicy={{ .Values.dataPlane.service.externalTrafficPolicy }} preserves client IPs for server identification)

4. Distribute the enterprise root CA to servers with the installer commands shown under TLS & CA in the
   console: they check the script's SHA-256 before running it as root/Administrator. Never pipe the
   scripts into a shell. Manually, from a fresh private directory (the checked file is the one that runs):
   d=$(mktemp -d); curl -fsSLo "$d/aegis-ca-install.sh" {{ .Values.publicUrl }}/api/public/ca/install-linux.sh
   sha256sum "$d/aegis-ca-install.sh"          # must match the console
   sudo bash "$d/aegis-ca-install.sh"; rm -rf "$d"
   Windows: $d = New-Item -ItemType Directory -Path (Join-Path $env:TEMP ('aegis-ca-' + [guid]::NewGuid())); $f = Join-Path $d.FullName 'aegis-ca-install.ps1'
            iwr -UseBasicParsing {{ .Values.publicUrl }}/api/public/ca/install-windows.ps1 -OutFile $f
            Get-FileHash $f -Algorithm SHA256   # must match the console
            powershell -NoProfile -ExecutionPolicy Bypass -File $f; Remove-Item -Recurse $d.FullName
{{- if and (not .Values.ca.existingSecret) .Values.ca.generate }}

NOTE: the CA was generated by Helm (RSA-2048). For production create it with
      `aegis-control-plane gen-ca` and reference it via ca.existingSecret.
{{- end }}
{{- if and .Values.ingress.enabled (not .Values.ingress.trustedController.enabled) (not .Values.controlPlane.trustedProxies) (not .Values.controlPlane.trustedProxyHosts) }}

NOTE: no proxy is trusted, so the control-plane sees the ingress controller as the client of every request
      (per-IP login and SCIM lockouts hit everyone, the audit trail records the controller's address).
      Trust exactly the controller pods with ingress.trustedController.enabled=true (headless Service by
      their labels in their namespace). Never trust a pod CIDR: every pod could then forge its address.
{{- end }}
