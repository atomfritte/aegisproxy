AegisProxy {{ .Chart.AppVersion }} deployed (storage: {{ .Values.storage.type }}, control-plane replicas: {{ include "aegis.cpReplicas" . }}).

1. Console / API
{{- if .Values.ingress.enabled }}
   https://{{ .Values.ingress.host }}
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aegis.cpService" . }} 8081:{{ .Values.controlPlane.service.port }}
   then open http://127.0.0.1:8081  (set publicUrl to the real external URL!)
{{- end }}

2. Bootstrap Super Admin "admin" password:
{{- if .Values.secrets.existingSecret }}
   key "bootstrap-admin-password" in Secret {{ .Values.secrets.existingSecret }} (or DATA_DIR/secrets/initial-admin-password)
{{- else }}
   kubectl -n {{ .Release.Namespace }} get secret {{ include "aegis.secretName" . }} -o jsonpath='{.data.bootstrap-admin-password}' | base64 -d; echo
{{- end }}
   Change it after the first login and create personal accounts.

3. Proxy endpoint for servers:
   kubectl -n {{ .Release.Namespace }} get svc {{ include "aegis.fullname" . }}-proxy
   (externalTrafficPolicy={{ .Values.dataPlane.service.externalTrafficPolicy }} preserves client IPs for server identification)

4. Distribute the enterprise root CA to servers with the installer commands shown under TLS & CA in the
   console: they check the script's SHA-256 before running it as root/Administrator. Never pipe the
   scripts into a shell. Manually:
   curl -fsSLo aegis-ca-install.sh {{ .Values.publicUrl }}/api/public/ca/install-linux.sh
   sha256sum aegis-ca-install.sh          # must match the console
   sudo bash aegis-ca-install.sh
   Windows: iwr -UseBasicParsing {{ .Values.publicUrl }}/api/public/ca/install-windows.ps1 -OutFile aegis-ca-install.ps1
            Get-FileHash aegis-ca-install.ps1   # must match the console
            powershell -NoProfile -ExecutionPolicy Bypass -File .\aegis-ca-install.ps1
{{- if and (not .Values.ca.existingSecret) .Values.ca.generate }}

NOTE: the CA was generated by Helm (RSA-2048). For production create it with
      `aegis-control-plane gen-ca` and reference it via ca.existingSecret.
{{- end }}
{{- if and .Values.ingress.enabled (not .Values.controlPlane.trustedProxies) }}

NOTE: controlPlane.trustedProxies is empty, so the control-plane sees the ingress controller as the client
      (shared rate limits, audit IPs of the ingress). Set it to the pod CIDR of your ingress controller.
{{- end }}

WARNING: publicUrl is http:// - session cookies are not Secure and the CA install scripts can be tampered
         with in transit. Use https:// in production.
{{- end }}
